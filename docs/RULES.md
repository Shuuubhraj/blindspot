# Blindspot detection rules

**120 rules**, generated from the live registry (`scripts/gen_rules_doc.py`). Do not hand-edit the tables below - regenerate.

Severity distribution: critical: 3, high: 34, medium: 63, low: 10, informational: 10

Rules per category: auth: 10, crypto: 15, manifest: 20, network: 20, platform: 20, storage: 20, webview: 15

Notes:
- **Severity** is the default impact rating; **confidence** is assigned per
  finding at scan time and is an independent dimension (see `docs/SECURITY.md`).
- **OWASP** maps to the OWASP Mobile Top 10: 2024 (M1–M10).
- **MASVS** uses verified category codes only (`MSTG-*`); numbered IDs are
  never invented.
