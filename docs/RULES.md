# Blindspot detection rules

**200 rules**, generated from the live registry (`scripts/gen_rules_doc.py`). Do not hand-edit the tables below - regenerate.

Severity distribution: critical: 3, high: 64, medium: 91, low: 23, informational: 19

Rules per category: auth: 15, crypto: 15, manifest: 20, network: 35, platform: 20, secrets: 20, storage: 25, supply-chain: 20, webview: 30

Notes:
- **Severity** is the default impact rating; **confidence** is assigned per
  finding at scan time and is an independent dimension (see `docs/SECURITY.md`).
- **OWASP** maps to the OWASP Mobile Top 10: 2024 (M1–M10).
- **MASVS** uses verified category codes only (`MSTG-*`); numbered IDs are
  never invented.
